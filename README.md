AFYA KWA WOTE
Application enabled a client to book a doctor of choice from anywhere without the need to physically go to a hospital and book for a consultation, 06th August 2026;
By James Gacheru
Description
A website that allows patients in Kenya to search for doctors by specialty, hospital, location, and available time, then book appointments online from home. It can also support same-day booking when slots are available, helping patients avoid long queues and receive care more conveniently.
Setup/Installation Requirements
Run the link on the repository
